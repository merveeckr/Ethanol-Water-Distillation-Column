# Ethanol Distillation — Group 7

Ankara Üniversitesi Gıda Mühendisliği Bölümü, FDE 450 Process Design dersi kapsamında hazırlanmış interaktif proje raporu. Mısır bazlı fermantasyon sıvısından yakıt sınıfı biyoetanol üretimi için tasarlanan sürekli damıtma kolonunu ve McCabe-Thiele analizini içermektedir.

## İndirme

**Seçenek 1 — ZIP olarak indir (Git gerekmez)**

1. GitHub'da repo sayfasını açın
2. Sağ üstteki yeşil **Code** butonuna tıklayın
3. **Download ZIP** seçin
4. İndirilen `.zip` dosyasını bir klasöre çıkartın

**Seçenek 2 — Git ile klonla**

```bash
git clone https://github.com/KULLANICI_ADI/REPO_ADI.git
```

> `KULLANICI_ADI` ve `REPO_ADI` kısmını GitHub'daki gerçek adresle değiştirin.

## Kurulum

Herhangi bir kurulum gerekmez. Proje tamamen statik HTML'den oluşmaktadır.

## Siteyi Açmak

`index.html` dosyasına çift tıklayın — doğrudan tarayıcıda açılır.

> İnternet bağlantısı gereklidir. Grafik ve matematiksel gösterimler CDN üzerinden yüklenen Chart.js ve KaTeX kütüphanelerini kullanır.

## Sitede Neler Var?

Tek sayfalık bir web sitesidir ve aşağıdaki bölümleri içerir:

| Bölüm | İçerik |
|---|---|
| **Summary** | Temel tasarım parametreleri — üretim kapasitesi (100.000 L/gün), saflık, kolon boyutları |
| **Introduction** | Biyoetanolün enerji bağlamı, azeotrof davranışı ve McCabe-Thiele yönteminin açıklaması |
| **Materials & Methods** | Tasarım adımları, denge denklemleri ve varsayımlar |
| **Results** | Akış dengeleri, geri akış oranı, kademeli hesaplamalar ve kolon hidroliği (sekme bazlı) |
| **Economics** | Doğrudan/dolaylı gider kırılımı ve toplam yatırım maliyeti (₺21,46 M) |
| **Conclusion** | Tasarım sonuçları ve gelecek çalışmalar için öneriler |

Sayfada animasyonlu sayılar, interaktif grafikler (VLE eğrisi, McCabe-Thiele diyagramı, ekonomi grafiği) ve kaydırma efektleri bulunmaktadır.
